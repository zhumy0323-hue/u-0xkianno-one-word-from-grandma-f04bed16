## The word

**jeepers**

## Why this is the word grandma would send

You tell grandma a computer can now write poems, answer questions, and
talk back like a person, and she does not reach for tech jargon or a
careful sentence. She reaches for the delighted old-fashioned
exclamation she has used since forever: "jeepers". It is pure
wide-eyed amazement in a single word, the kind of thing she would
thumb out with a smile before following up with three more questions
about whether the computer is a nice boy. No punctuation, no
explanation, just the amazement itself — exactly how she texts.

## How to run

```sh
python3 main.py
```

This writes the word to `/output/entry.txt` (UTF-8, one word, no newline).
